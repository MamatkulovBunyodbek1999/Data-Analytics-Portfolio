# SQL + Pandas Sales Analysis Project

## 📌 Overview
This project demonstrates end-to-end data analysis using SQL and Python (Pandas).  
The goal is to analyze sales data, extract insights, and support business decision-making.

---

## 🎯 Objectives
- Load raw sales data into a database
- Perform data cleaning and transformation using Pandas
- Run SQL queries for business insights
- Identify key performance metrics such as revenue, top products, and customer behavior

---

## 🧰 Tools & Technologies
- Python (Pandas)
- SQLite (SQL)
- Jupyter Notebook / VS Code
- CSV dataset

---

## 📂 Dataset
The dataset contains retail sales transactions with columns such as:
- Order Date
- Sales
- Category
- Product Name
- Customer Name
- (and other supporting attributes)

---

## ⚙️ Process Workflow

### 1. Data Loading
- Imported CSV dataset using Pandas
- Cleaned column names for consistency
- Loaded data into SQLite database

### 2. SQL Analysis
Executed SQL queries to extract insights:
- Total revenue calculation
- Sales by category
- Top-selling products
- Monthly sales trends
- Top customers by revenue

### 3. Data Export
- Exported query results back to CSV for reporting and visualization

---

## 📊 Key Insights
- Certain product categories generate significantly higher revenue
- A small group of customers contributes to a large portion of total sales
- Sales trends show variation across time periods
- Top products dominate revenue distribution
