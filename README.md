# API Data Pipeline Project

## Objective
Extract and analyze cryptocurrency data using an external API.

## Tools Used
- Python
- Pandas
- REST API
- JSON

## Process

- Converted JSON to structured format
- Cleaned dataset using Pandas
- Identified top 10 cryptocurrencies by market cap

## Output
- crypto_data.csv
- top10_crypto.csv

Top cryptocurrencies dominate the market significantly compared to others.
